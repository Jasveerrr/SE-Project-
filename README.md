# SwiftShare

Production-grade project scaffold for a local-first file sharing platform.

## Stack

- Frontend: React, Vite, Tailwind CSS v4, React Router, Axios, Zustand, React Hook Form, Zod, Framer Motion, Lucide React
- Backend: Node.js, Express, Socket.IO, JWT, bcrypt, Multer, Prisma, SQLite, PostgreSQL

## Scripts

- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run format`
